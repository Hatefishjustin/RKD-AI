# 宁波协诚 DWG/DXF 逐对象交叉核对报告

生成时间：2026-09-21

## 1. 核对方法

DXF 导出保留了原 CAD 实体句柄。本轮以实体句柄作为身份键，对 DXF 主平面候选与 DWG 候选逐项比较：

- 图层；
- 专业类别；
- 实体类型；
- 直线、折线、圆等直接实体的边界；
- 圆弧在 0.5 mm 采样容差下的边界；
- `INSERT` 完成基础 2D 展开后的块边界。

普通直接实体和块边界容差为 0.01 mm。该方法用于发现解析差异，不替代专业对象确认。

## 2. 核对结果

| 指标 | 数量 |
| --- | ---: |
| DXF 主平面候选 | 754 |
| DWG 主平面候选 | 831 |
| 同句柄候选 | 640 |
| 通过逐对象核对 | 640 |
| 同句柄但需复核 | 0 |
| DXF 独有 | 114 |
| DWG 独有 | 191 |
| 创建专业对象 | 0 |
| 可计量对象 | 0 |

640 个同句柄候选的图层、专业类别和实体类型全部一致，几何边界均在相应容差内。其中 70 个为块实例，DXF 与 DWG 的展开边界全部在 0.01 mm 内一致。

## 3. 非交集项解释

### DXF 独有 114 项

- `cad.reference`：108 项；
- `drawing.external-reference`：6 项；
- 实体类型：83 条 `LINE`、31 条 `LWPOLYLINE`。

这些全部属于辅助/外部参考类别，不是当前 DWG 专业候选筛选集中的墙、门、家具或工程量对象。

### DWG 独有 191 项

| 实体类型 | 数量 |
| --- | ---: |
| MTEXT | 54 |
| INSERT | 35 |
| TEXT | 29 |
| LEADER | 25 |
| HATCH | 25 |
| DIMENSION_LINEAR | 23 |

其中专业类别包括：插座 98、开关 59、地坪线 16、墙 8、固定家具 7、天花 3。它们主要是本轮 DXF 直接几何审查刻意排除的文字、引线、尺寸、填充和部分仅由块/注释表达的证据，不能直接判定为 DXF 丢失构件。

## 4. 当前可信结论

可以确认：

- 两个解析通道对 640 个保留句柄的主平面候选身份和类别判断一致；
- 570 个非块直接/圆弧候选与 70 个块展开候选的边界均在既定容差内；
- 基础基点、缩放、旋转和嵌套块变换在这 70 个共同块实例上相互印证。

仍不能确认：

- 133 个几何组就是最终墙、门或家具数量；
- 70 个闭合区就是房间或工程量面积；
- HATCH、文字、尺寸、引线和仅单通道出现的块证据可以忽略；
- 图纸尺寸等同于现场实测；
- 当前成果可用于施工或正式报价。

对象升级状态继续保持 `not-approved`，工程量状态继续保持 `not-ready`。下一轮专业抽查应优先检查 DWG 独有的 25 个填充和 35 个块证据，以及墙、地坪、固定家具、天花对应的 34 个当前范围非交集项。
