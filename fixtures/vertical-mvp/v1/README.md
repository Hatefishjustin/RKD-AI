# 真实资料接入说明

真实资料可以晚些提供。系统目前接受脱敏后的第一批样本，建议先提供一个项目、一个楼层或主要空间区域，文件名保持稳定。

## 建议资料

1. 现场平面图：`DWG`、`DXF`、`PDF` 任一种，最好附单位和比例说明。
2. 现场照片：`JPG`、`PNG`，标注拍摄位置或房间名称。
3. 材料表：`XLSX`、`CSV` 或 `PDF`，保留物料名称、规格、单位和数量。
4. 报价文件：`XLSX`、`CSV` 或 `PDF`，可以先隐藏客户姓名、电话、地址和金额敏感信息。
5. 如果存在 BIM 文件：提供原生文件和可交换格式，并说明软件、版本、字体和插件依赖。
6. 一份人工确认的“正确结果”或问题清单，用来比较图纸、工程量和报价的差异。

## 提供前请处理

- 删除客户姓名、电话、身份证号、住址、门牌号和未授权的人员照片；
- 保留文件之间的对应关系，不要只提供孤立截图；
- 不要把真实密码、API Key、供应商账号或付款信息放入文件；
- 如果暂时无法完全脱敏，可以先提供文件目录、格式、大小和依赖说明，不必上传原文件。

收到后会先登记文件指纹、来源、分级和扫描状态，再进入需求和统一模型回放；原始文件不会直接交给 Agent 当作已验证事实。
