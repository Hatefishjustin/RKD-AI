# 七、钉钉集成指南（按权限递进，每级都可独立运行）

> 原则：先用最低权限跑起来，再逐步申请高级能力。每一级都不依赖上一级以外的任何未确认信息。

## 级别 0：群机器人（最低要求，当天可用）

**前提**：钉钉群管理员。**用途**：接收 AI 整理结果、问题分派、到期提醒、日报周报、审批提醒。

1. 群设置 → 智能群助手 → 添加机器人 → 自定义（Webhook）。
2. 安全设置选"加签"或"自定义关键词"（建议关键词：`问题|任务|提醒|审批|日报|周报`）。
3. 把 Webhook 地址填入 n8n 环境变量（4 个群各一个，见部署说明）。
4. 消息格式为 markdown（工作流 JSON 中已内置），注意限流：每分钟 20 条/机器人。

**限制**：只能发消息，不能创建待办/审批；@人用 markdown 的 `@手机号`（需在 text 中同时附带）。

## 级别 1：钉钉宜搭（快速版主表单，1~2 天可用）

**前提**：企业认证 + 宜搭应用管理权限。

- 建 3 张表单，字段严格按 `02_数据模板/00_数据字典.md`：
  1. **施工问题提交表**：发现人（成员）、项目（下拉，来源项目表）、问题描述（多行）、照片（图片）、提交即触发"自动化规则"→ 群机器人播报。
  2. **供应商状态回填表**：任务（下拉）、最新状态（枚举）、预计完成日期、跟进摘要。
  3. **报价检查申请表**：项目、报价版本、Excel 附件。
- 宜搭"自动化"配置每日 9:00 定时提醒：查询未关闭问题/未完成任务 → 发提醒。
- 宜搭数据可导出 Excel，与 `02_数据模板/` 模板列一一对应，后续迁数据库零改造。

## 级别 2：钉钉待办与审批（稳定版增强）

**前提**：企业内部应用（自建应用）开发者权限。

- **待办 API**：问题分派时创建责任人待办（`POST /v1.0/todo/users/{unionId}/tasks`），完成整改后闭环；替代"群里@没人看到"的问题。
- **审批 API**：把"老板待审批清单"接入钉钉审批（宜搭流程或自建审批模板），老板在手机上直接同意/驳回；n8n 通过回调更新 `approvals.boss_decision`。
- 需要的权限：待办读写、审批实例读写、通讯录只读（unionId 映射）。
- 获取 unionId：通讯录 API 按手机号查询；n8n 中建一张 `staff_mapping` 小表维护姓名↔unionId。

## 级别 3：自建应用工作台（可选，第 2 个月以后）

把"提交问题、供应商状态、报价检查、待审批清单"做成 H5 页面挂进钉钉工作台，替代表单入口；数据直连 PostgreSQL。仅在级别 0~2 运行顺畅、团队适应后再考虑。

## 降级对照表

| 能力需求 | 不可用时的替代 |
|---|---|
| 群机器人 | 人工在群内粘贴 AI 生成文本 |
| 宜搭 | 钉钉在线表格 + 本包 Excel 模板 |
| 待办 API | 群机器人 @手机号 + 日报点名 |
| 审批 API | 老板机器人消息 + 口头决策，管理员代录 `approvals` 表 |

## 团队使用规范（写进群公告）

1. 施工问题一律走表单，不散落群聊；紧急问题表单提交后电话责任人。
2. 供应商回复由采购责任人 24h 内转填状态表单。
3. 群里只讨论异常和决策，正常进度看日报。
