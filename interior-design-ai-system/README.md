# 室内设计公司 AI 工作链系统 · 实施交付包 V1.0

> 一句话定位：先以一个企业空间项目为试点，用钉钉承载协同、飞牛 NAS 承载资料、结构化数据库承载项目状态、AI Agent 负责整理和判断、自动化平台负责触发和执行，让老板从日常催办和信息整理中退出，只保留设计、报价、合同、质量和重大风险的最终决策权。

本包是可直接交给实施人员执行的完整文件集，覆盖交接说明第 12 节要求的全部交付物。生成日期：2026-09-09。

## 实施顺序（三步走）

1. **低代码快速版（第 1~2 周）**：钉钉宜搭表单（或钉钉在线表格）+ 群机器人提醒 + 本包 Excel 模板。不部署任何新系统，先让"施工问题登记"和"供应商任务"跑起来。
2. **稳定内用版（第 3~6 周）**：飞牛 NAS Docker 部署 n8n + PostgreSQL + Dify，导入本包 `db_init.sql` 建表、导入 n8n 工作流、配置 Dify 中的 9 个 Agent。三条工作链全自动流转。
3. **定制扩展版（第 2 个月起）**：按 90 天计划接入钉钉自建应用（待办/审批 API）、设计协同链、供应商评分月报、住宅业务模板。
4. **设计 AI 试用（第 4 周起并行）**：生图/效果图渲染/CAD 辅助的选型见 `09_设计工具AI选型/`，先零成本试用即梦与云端生图，再决定是否购置显卡或酷家乐。

## 本版采用的默认假设（后续可替换，不影响文件结构）

以下问题在交接说明中未获回答，本包按默认假设执行；拿到真实信息后只需替换数据，不需改结构：

| # | 未确认问题 | 本版默认假设 |
|---|---|---|
| 1 | 试点项目是哪一个 | 任选一个"近期启动、资料相对齐全"的企业空间项目，编号规则 `HZ/NB/WZ-26-001` 起编 |
| 2 | 采购/供应商由谁负责 | MVP 阶段默认"助理设计师"为采购跟进责任人，老板只接升级项 |
| 3 | 供应商沟通渠道 | 以微信/电话为主；MVP 由责任人在钉钉表单转填状态，不做微信自动抓取（合规与稳定性风险） |
| 4 | 现有报价单格式 | 按 `02_数据模板/05_报价模板_企业空间.xlsx` 的通用结构重建；拿到真实报价单后把历史条目灌入工程项目库 |
| 5 | NAS 型号/Docker 能力 | 假设飞牛 NAS 支持 Docker 且可长期联网（绝大多数飞牛机型支持），PostgreSQL 容器数据量极小 |
| 6 | 钉钉权限 | 假设可创建群机器人（最低要求）；宜搭、自建应用、审批 API 为增强项，不可用时按指南降级方案执行 |
| 7 | 大模型选型 | 优先国内合规云 API（智谱 GLM / 通义 / DeepSeek 等），合同、客户隐私信息先脱敏再进入 AI |

**重要**：`05_报价模板_企业空间.xlsx` 中的所有单价均为示例占位数据，上线前必须用公司真实价格库替换，替换前不得用于正式对外报价。
