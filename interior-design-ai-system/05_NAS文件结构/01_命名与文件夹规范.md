# 八、NAS 文件结构与命名规范

> 飞牛 NAS 建一个共享文件夹 `室内设计公司`，在其中执行 `create_structure.sh`（fnOS/Linux）或 `create_structure.bat`（Windows）一键建目录。

## 1. 目录结构（与交接说明一致，细化到用途）

```text
室内设计公司/
├── 00_公司知识库/          # 公司制度、流程文档、本交付包的执行版本
│   ├── 01_流程与制度/
│   ├── 02_标准与规范/      # 施工图标准、验收标准
│   └── 03_培训与交接/
├── 01_客户线索/            # 未签约项目的零散资料（签约后整体移入 02）
├── 02_进行中项目/
│   └── HZ-26-001_客户简称/
│       ├── 01_客户资料/    # 合同附件、客户提供的原始资料
│       ├── 02_现场测量/    # 量房记录、现场照片（按 yyyyMMdd_部位 命名）
│       ├── 03_设计方案/    # 平面、方案文件（版本化）
│       ├── 04_效果图/      # 渲染成品与源文件分开：_成片 / _源文件
│       ├── 05_CAD施工图/   # 图纸版本 v1/v2/v3，只增不改
│       ├── 06_报价与合同/  # Q01/Q02 报价、合同扫描件
│       ├── 07_材料与供应商/# 打样照片、订单、供应商报价单
│       ├── 08_施工进度/    # 日报、进度照片（按周分文件夹）
│       ├── 09_变更与问题/  # 问题照片与整改记录（AI 归档目标）
│       └── 10_验收与售后/  # 验收单、售后记录
├── 03_已完成项目/          # 验收后整目录移入，结构不变
├── 04_供应商库/            # 各供应商资质、历史报价、评分记录
├── 05_材料库/              # 材料样块照片、检测报告、色卡
├── 06_模板库/              # 报价模板、合同模板、表单模板、本包 02 目录镜像
└── 99_归档与备份/          # 周打包快照（配合备份策略）
```

## 2. 命名规范

| 对象 | 规则 | 示例 |
|---|---|---|
| 项目文件夹 | 项目编号_客户简称 | HZ-26-001_某科技 |
| 报价文件 | 项目编号-Qxx-日期 | HZ-26-001-Q01-20260905.xlsx |
| 合同 | 项目编号_合同类型_日期 | HZ-26-001_设计施工合同_20260912.pdf |
| 施工图 | 图名-v版本-日期 | 平面布置图-v3-20261001.dwg |
| 效果图 | 空间_视角-v版本 | 前台_主视角-v2.jpg |
| 现场照片 | 日期_部位_序号 | 20260905_二层隔墙_01.jpg |
| 问题整改照片 | 问题编号_前/后_序号 | WT-26-0001_后_02.jpg |
| 会议纪要 | 项目编号_纪要_日期 | HZ-26-001_纪要_20260918.md |

**三条铁律**：
1. 版本只用 `v数字` 递增，禁止 `最终版/最新版/改` 等命名；发客户的 PDF 用 `-定稿` 后缀且源文件不动。
2. 交付物先入对应阶段目录，再更新数据库/表单；顺序不能反。
3. 手机拍摄现场资料当天传 NAS（钉钉→助理归档），不过夜留在微信里。

## 3. 权限建议（fnOS 共享文件夹权限）

| 目录 | 老板 | 助理设计师 | 效果图 | 施工图 | 行政财务 | 外包施工 |
|---|---|---|---|---|---|---|
| 00_公司知识库 | 读写 | 读写 | 读 | 读 | 读 | 无 |
| 01_客户线索 / 02_进行中项目 | 读写 | 读写 | 对应项目读写 | 对应项目读写 | 读 | 仅 08/09 可写、无下载合同权限 |
| 03_已完成项目 | 读写 | 读 | 读 | 读 | 读 | 无 |
| 04_供应商库 / 05_材料库 | 读写 | 读写 | 读 | 读 | 读 | 无 |
| 06_模板库 | 读写 | 读 | 读 | 读 | 读 | 无 |
| 99_归档与备份 | 读写 | 无 | 无 | 无 | 无 | 无 |

**注意**：报价与合同目录（06）含商业机密，外包人员账号禁止访问；成本相关 Excel 只存老板与行政可见位置（或数据库隔离）。

## 4. 备份策略（NAS 不能是唯一备份）

- 每日 23:00：PostgreSQL `pg_dump` → `99_归档与备份/db/`；n8n 配置导出 → 同目录。
- 每周六：`99_归档与备份` 打包快照，保留最近 4 份。
- 每月：快照同步一份到云端（阿里云 OSS/百度网盘等任选）或第二块硬盘；**异地/第二介质备份缺一不可**。
- 每季度做一次恢复演练：随机抽 1 个文件和 1 张数据库表恢复验证。
