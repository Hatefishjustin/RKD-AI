# 待复核裁定（受控反馈修订）

本批不宣布 W3 通过、不宣布设计通过、不放行真实模型试验、不推进阶段/W4，交架构复核。

## D1 锁定令牌范围

当前支持：入口（`entrance`/`保留入口`/`入口`）、展陈（`display`/`保留展柜`/`保留展示`/`保留主展台`/`保留展陈`）、显式 `object_id`、场地快照摘要。

请裁定：是否需要扩展为结构化锁定契约（字段级、材料/照明/造价分别锁定）？现有 `locks` 仍是 `list[str]`，非结构化。

## D2 反馈解析强度

当前要求 `parsed_intents` 非空或显式 `conflicts`，否则 `FEEDBACK_UNPARSED`。这是对模型输出的硬门槛；若真实模型常以自然语言给出无法结构化的意图，需要确定是重试、拒绝还是人工介入。

## D3 父链与采用指针

反馈修订成功后**不**自动改写 adoption 当前指针，也不递增 adoption version；只新增 revision 并登记父链。请裁定是否需要在采用记录里显示"存在未采用的更新修订"。

## D4 PG / HTTP / 浏览器

本批仅在 SQLite + ApiService 公共方法上验证。PG 数据面无实例、HTTP 进程与浏览器 UI 未起，均 not_run。是否需要本批后补，或在架构复核中接受该边界。

## D5 真实模型授权

本批未调用、未外发、未花费。若要把这条路径切到真实模型，需要明确外部调用类别、次数、费用上限与资料外发范围；本批不提出申请。

## D6 定性

桩来源、不是 AI 设计成果、不计 AD01—AD08；用户否决仍为 AD08 真实负例，未获新认可。
