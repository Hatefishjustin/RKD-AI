# C1 解析手算（期望值来源）

本批所有期望值都用**分段解析积分**独立给出，不拿被测实现当标准答案。
被测实现有两条路径：主量（Shapely 精确并/交）与独立复算（竖条带积分，只用原始顶点）。
整改要求：两条路径都必须等于解析值，且饰面量以精确几何为主值、条带只做交叉校验。

## 1. 架构给的口径：三角形 18㎡ 扣 4.5㎡ = 13.5㎡

- 三角形 (0,0),(6000,0),(0,6000)（mm），面积 18 ㎡。
- 扣除矩形 x∈[0,6000], y∈[1000,2000]。
正确做法是对 x 逐段积分被**斜边**截断的长度：

- 交集上边界 = min(6000−x, 2000)，斜边与 y=2000 的交点在 x=4000。
- ∫₀⁴⁰⁰⁰ (2000−1000)dx + ∫₄₀⁰⁰⁶⁰⁰⁰ ((6000−x)−1000)dx
  = 4000×1000 + [5000x − x²/2]₄₀₀₀⁶⁰⁰⁰
  = 4 000 000 + (18 000 000 − 14 000 000) = 4 500 000 mm² = **4.5 ㎡**
- 净 = 18 − 4.5 = **13.5 ㎡**；饰面量同口径 13.5 ㎡；假设单价 1000 元/㎡ → **13 500 元**。

旧实现的数值：主几何量 13.5（Shapely 一直是对的）、独立复算 12.0、饰面量 12.0、金额 12 000 元。
旧条带只在顶点 x=0 与 x=6000 处切分，整段按中点 x=3000 取截面：
三角形区间 [0,3000]、扣除区间 [1000,2000]，截面长度 2000，条带宽 6000
→ 2000×6000 = 12 000 000 mm² = 12 ㎡。被积函数在条带内**不是线性**
（先是被斜边压缩、再被矩形下边截断），中点值因此系统性偏小 1.5 ㎡。
整批用例 W2C2-C1-01 在整改前 fail（12.0/12000），整改后 pass（13.5/13500）。

## 2. 判别性真实入口：保留区竖直带（9.4224 ㎡）

面 (22000,0),(26170,0),(22000,8340)：两条直角边 4170 与 8340，毛面积
0.5×4170×8340 = 17 388 900 mm² = 17.3889 ㎡。
卫生间保留区 (22000,2600)–(26170,7300)。斜边 y = 8340 − 2(x−22000)。

断点（被积函数在此改变表达式）：
1. 斜边 = 7300 → x = 22 520；
2. 斜边 = 2600 → x = 24 870；
3. 面右上角 x = 26 170。

- x∈[22000,22520]：扣除长度 = 7300−2600 = 4700 → 520×4700 = 2 444 000
- x∈[22520,24870]：扣除长度 = (8340−2(x−22000))−2600 = 5740−2(x−22000)
  = [5740u−u²] u从520到2870 = 8 236 900 − 2 714 400 = 5 522 500
- x∈[24870,26170]：斜边低于 2600，扣除 0

扣除合计 = 7 966 500 mm² = 7.9665 ㎡ → 净 = 17.3889 − 7.9665 = **9.4224 ㎡**，
单价 1000 元/㎡ → **9 422 元**。

旧实现整段只有一个条带（顶点 x 只有 22000/26170），按中点 x=24085 取截面：
扣除 1570×4170 = 6 546 900 → 饰面量 **10.842 ㎡**、金额 **10 842 元**（偏大 1.42 ㎡ / 1 420 元）。
整改前 W2C2-C1-08 记录的正是 10.842/10842；整改后 9.422/9422，与解析一致。

## 3. 函数级第二例：扣除区斜穿斜边（17.405 ㎡）

三角形同上；扣除矩形 x∈[2500,3500], y∈[2400,3400]。
斜边与矩形下边 y=2400 交点 x=3600？——按公式 y=6000−x：y=2400 → x=3600；
与上边 y=3400 → x=2600。矩形 x∈[2500,3500] 分三段：

- x∈[2500,2600]：上界 6000−x ≥ 3400 → 长度 = 3400−2400 = 1000 → 100 000
- x∈[2600,3500]：上界 6000−x ∈ [2500,3400] → 长度 = (6000−x)−2400 = 3600−x
  = ∫₂₆₀₀³⁵⁰⁰(3600−x)dx = 495 000
- 合计 595 000 mm² = 0.595 ㎡ → 净 18 − 0.595 = **17.405 ㎡**

## 4. 同层重叠夹具（22 ㎡ 并集，不是 24 ㎡ 相加）

- A1 = (0,0),(4000,0),(0,4000)：8 ㎡
- A2 = (2000,0),(6000,0),(6000,4000),(2000,4000)：16 ㎡
- 重叠 = A1 在 x≥2000 的部分 = ∫₂₀₀₀⁴⁰⁰⁰(4000−x)dx = 2 ㎡
- 并集 = 8 + 16 − 2 = **22 ㎡**；未声明重叠时必须拒绝，声明后按并集计量。

## 5. 诚实记录：本批修过一次自己的解析工具

第一版解析工具只切了「斜边=矩形上边」一个断点，把 9.4224 算成 11.1124，
并因此一度把整改后的 9.422 判成 FAIL（repro-after 第一次运行 C1-08 失败）。
核对发现**被测实现的两条路径一致且正确**，是期望值漏了「斜边低于保留区下边」的断点
（x=24870），补上后四个解析值全部与实现吻合（4.5 / 7.9665 / 2.0 / 17.3889）。
