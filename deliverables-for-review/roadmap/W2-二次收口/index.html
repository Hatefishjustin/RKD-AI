2. 三条缺陷的机制与修法

  • C1 计量：旧条带只在顶点 x 切分，斜边与保留区边界相交处截面长度非线性，中点采样系统性偏差； 饰面量又直接把这条复算当业务主值。→ 断点补齐边-边交点；饰面量改精确几何为主值、条带只做交叉校验， 差值超容差即 disputed（不给数值、不试算金额）。单位契约 mm/m2 之外拒绝； 无效多边形/重复 object_id/同层重叠无声明拒绝。
  • C2 恢复误杀：提交事务已落库、worker 尚未登记进内存集合时，任何状态查询都会把正常任务写成 failed/WORKER_RESTARTED。→ 任务持久化 run_instance，恢复只回收其他实例遗留， 内存集合不再参与判定；取消/晚到渲染/显式重试语义不变（见 c2-race-evidence.md）。
  • C3 按 ID 串成果：显式查询先扫"全局最新 50 条"再找 ID，找不到就回退到别的成果。→ 主键直查、 不回退、两参数冲突 400；类型过滤下沉 SQL 后分页；默认概览续看上一份成功成果但明确标注 （见 c3-id-and-history.md）。
