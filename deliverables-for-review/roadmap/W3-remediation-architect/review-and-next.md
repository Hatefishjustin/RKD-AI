## 需整改问题

1. **[P1] 场地输入未贯穿生成与校验。** `scripts/verify_w3_adapter_remediation.py:254` 调用真实 provider 时传入 `manual_boundary_not_site_verified` 和空障碍，provider 用 [0, 2.24] 作入口；后面的适配器另用 [0, 10.3] 及底图保留区。实际包中 `path-south` 矩形穿过楼梯保留区 3.072㎡，其中心线入口为 [0, 2.24]；输出入口与该中心线端点相距 8.06m。检查只证明加了保留区字段，未证明设计基于相同底图和入口生成、校审。必须把同一带来源及假设的场地快照送入 provider、模型适配和校验；保留区冲突、入口不连通应失败或明确阻止作为有效候选，不得静默重绑。使用隔离本地桩验证正例及入口错位、楼梯/湿区冲突、几何变化负例；证明调用前后使用相同哈希，并检查最终成果的全部动线与障碍。若旧契约阻止该路径，应明确阻塞并解决契约，而非仅改标签。
2. **[P1] 运行来源和父链仍可自行伪造。** `realmodel_spatial_adapter.py:361` 只检查调用者指定 JSON 的自报字段和自包含 SHA；任何人都能构造 `kind=real_model_run`、`simulated=false`、候选摘要和任意 input/output/project 再计算 SHA，即被判真实。父链 416 行只比对记录内候选摘要，不比较父 revision ID、项目、谱系或该记录与子版本的关系。独立使用内存模拟文件重现：伪造记录被标 real_model，任意 parent 被标 verified。摘要只能证明记录内部一致，不证明产生来源或模型调用。先只允许来自受控运行服务/仓储的不可随入参自报的来源记录与实际输出、项目、请求和修订链关联；缺证据时保持 unknown/fixture，不能发出已验证真实来源。设计明确可信边界，校验记录身份、输入/输出哈希、项目及父链，测试完整伪造、跨项目、篡改和错误父 ID。不要把额外一层自算 SHA 称作真实性证明。
3. **[P1] 持久候选转换丢失设计事实且未完整留痕。** `candidate_from_persisted`（830 行）只按少数对象种类抽取，未传递 `relationships`、对象 `material_id`、部分来源及 focal 结构；未知对象种类会静默跳过。实际样本源 focal 被变成普通家具，目标 `platforms=[]`，关系为空；输出却将关系概括成 semantic_only，并非逐项对账。新增按源 revision / 完整模型摘要的字段映射和损失清单；对未知 kind/几何/字段必须显式标 unsupported/unknown 或拒绝，不能静默漏掉。构造含关系、不同材料绑定、焦点、未知对象和非矩形的持久候选，逐字段比较，确保不伪造新形状及不丢失设计意图。
4. **[P2] 契约方案仍是同版本不同验证器。** `contract-evolution.md` 方案保持 `rkd-ai-design-option.v1`，却要求选择另一份对旧 schema 不兼容的完整 schema；消费者仍只加载旧主契约，故不能称单一权威版本或 additive 兼容。架构决定：先提交**可识别的顶层新版本**或将新分支正式纳入唯一权威契约的版本化修订方案，明确已有严格消费者如何升级及旧文档回归、持久化/采用边界；不得不改 schema_version 就靠调用方选择另一验证器。实验性对象不得进入正式采用链。新候选可持久化和采用的真实路径通过之后再申请正式接入。
5. **[P2] 图面与净宽口径未闭环。** 适配器虽写 `width_known_status=model_declared_unverified`，但 `ai_spatial_outputs.py:1327` 图例仍称“主动线（净宽 …）”，不能将模型矩形宽度表达为实际净宽。近方形路径使用零长中心线，仍可能画不出连接；最终图与场景必须显示声明宽度/待核状态，未知主轴显示轮廓或不验证，不能冒称连通。覆盖横/竖/近方及多段连接，验证最终图面文本和几何，而不仅校验中间字段。
6. **[P2] 验收与复跑边界。** `V-15` 只是直接从内存 ZIP 读取并比较字节，未经过 HTTP 下载，应改名及报告；`--no-render` 正确给 V-13—15 标 not_run，但仍生成无 render 的 ZIP，必须显式标记不完整且禁止登记成完整成果，不能因文件与清单一致而放行。核对完整性 gate 的实际消费者。验证脚本默认会删除指定 runtime 的 SQLite 并覆盖输出；独立复跑务必传新目录。R04 只证明指定主轴数值，不能推广为动线连接与现场合规。底图从 SVG 按尺寸猜第一个匹配项，需明确只适用固定已确认字节；同尺寸歧义时拒绝，后续底图使用带稳定 ID 的结构化数据，不扩成通用解析器。
