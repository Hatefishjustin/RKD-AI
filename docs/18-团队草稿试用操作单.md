# 团队草稿试用操作单

本操作单用于M5-06真实使用验收，不是工程测试通过证明，也不允许正式报价、施工发布、外部下单或付款。

入口：https://fnos-nas.tailcca6f8.ts.net:9443/ 。设备需连接同一Tailscale网络。

## 管理员准备

在“账号与成员管理”创建个人账号，分别给试用项目配置负责人、编辑或只读权限。在“审核岗位管理”为设计/图纸审核和报价/税务核验配置对应账号。岗位成员还须有该项目访问权限。制作者、送审提交者不能自审；可由同一名独立审核人员担任两个草稿岗位，但不因此获得正式签署权。人员变动可在管理页调整，不需改代码。

不共享个人密码，不使用原件或数据库目录充当临时运行数据。测试项目请在名称中标注“试用”，不要将测试尺寸称为现场实测。

## 跑通一版草稿

1. 负责人或编辑在需求草稿填写边界来源、展厅尺寸、通道、功能分区，保存需求并生成分区布局。测试或人工未核验边界保持来源标记。
2. 在生产区域填写本次地坪范围、未税单位成本及价格来源；成本未知时保留未知。施工成本加成20%、试用税率5%是既有试用口径，正式税务仍需专业核验。保存后查看真实工程量与报价草稿，下载成果。
3. 负责人点击“检查当前生产草稿”，处理软件提示的缺项后“按岗位提交草稿审查”。没有有效接收人显示待配置，不等于已经送达。
4. 独立审核人员用本人账号打开顶部待办，下载本版审核包，核对版本和具体文件。逐项填写结果、依据及本版成果引用；不能核验就选“未核验”并说明原因。需修改项目对应整体“需要修改”。保存意见不等于专业批准。
5. 负责人在项目审查记录查看意见与当前版本汇总。修改需求、设计或价格形成新版本后重新检查送审，旧结论不会沿用；旧成果和意见仍可追溯。

## 真实试用应反馈的结果

- 实际使用的项目与生产版本；角色是否各自完成上述操作。
- 下载成果是否能打开，面积/量价是否符合输入，未知和待核验提示是否清楚。
- 需要修改的具体步骤、错误信息和对应版本；不发送密码、密钥或数据库连接串。

这些结果必须来自真实使用人员。本系统的规则分区、地坪计算和程序测试不能代替现场边界、柱网、出入口、消防/无障碍、材料做法、市场价格、正式税务或合同专业判断。
